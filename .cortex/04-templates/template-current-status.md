# Template - Current Status

## Objetivo
Registrar o estado vivo do trabalho em um projeto específico, permitindo leitura rápida do ponto atual, das prioridades, dos bloqueios e da próxima ação recomendada.

Este documento pertence ao projeto.

Ele deve ser usado para acompanhamento contínuo do trabalho no contexto daquele projeto, sem depender de memória informal e sem usar arquivos globais do sistema para esse fim.

## Papel deste documento no projeto
Este arquivo existe para registrar o estado atual de um projeto específico.

Usar este documento para:
- mostrar onde o trabalho está agora
- registrar o que já foi levantado
- apontar o que está em andamento
- destacar o que ainda falta
- explicitar prioridades
- registrar bloqueios
- indicar a próxima ação mais útil

Este é um dos arquivos centrais de continuidade do projeto.

---

## Regra de fronteira

Este documento deve ser usado para acompanhamento do projeto.

O acompanhamento do projeto acontece em:
- `docs/context/current-status.md` (este arquivo)
- `docs/context/handoff.md`

Pendências e bloqueios do projeto vivem aqui, na seção apropriada — não em arquivos paralelos.

# Template - Handoff

## Objetivo
Garantir continuidade do trabalho em um projeto específico entre sessões, pessoas ou agentes, sem depender de memória informal.

Este documento pertence ao projeto.

Ele deve registrar o ponto de parada, os próximos passos e os cuidados necessários para uma retomada segura e eficiente.

## Papel deste documento no projeto
Este arquivo existe para facilitar a retomada do trabalho em um projeto específico.

Usar este documento para:
- registrar onde o trabalho parou
- indicar a última frente analisada
- explicitar o que já está pronto
- mostrar o que ainda precisa acontecer
- orientar a próxima retomada
- registrar alertas importantes
- evitar dependência de contexto implícito

Este é um dos arquivos centrais de continuidade do projeto.

---

## Diferença entre este documento e `current-status`
- `docs/context/current-status.md` registra o estado vivo e atual do projeto
- `docs/context/handoff.md` registra a passagem de contexto para retomada futura

Os dois documentos se complementam e devem ser mantidos consistentes entre si.

---

## Regra de fronteira

Este documento deve ser usado para continuidade do projeto.

A continuidade e o acompanhamento do projeto acontecem em:
- `docs/context/current-status.md` (estado vivo)
- `docs/context/handoff.md` (este arquivo, passagem de contexto)
